EcoJourney

A mobile web app that helps shoppers make more sustainable choices. Scan a product's barcode and instantly see its sustainability score and environmental impact.

My role
User research, API discovery, loading animation, accounts, friends, gamification
Tech
JavaScript, HTML, CSS
Data
SQLite · Open Food Facts API
Context
CMGT team project
CMGT Showcase pageView code on GitHub
My role

From research to gamification

I started with extensive user research, which led me to the Open Food Facts API that became the backbone of the project. I built the loading animation between a successful scan and the product page, and implemented accounts, friends and gamification: users earn points for every unique product they scan.

  • Barcode scanning with the phone camera.
  • Product and sustainability data from an API.
  • A clear sustainability score with alternatives.
Reflection

What I learned

This project strengthened my skills in API integration and gamification.
